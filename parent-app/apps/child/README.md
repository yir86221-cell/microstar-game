# 儿童端（未开始）

iPad 儿童端。P0 阶段还没动，这里只留结构位。

已经定下来的几件事（见架构文档）：

- **共用 `core-protocol` / `core-domain`**，不另写一套判分逻辑。
- 全屏、纯黑底、大色块、低频动画；对渲染性能要求很低。
- 锁屏用系统「引导式访问（Guided Access）」，不自己造 kiosk。家长端出一条开启指引。
- 训练中**默认关闭声音**：CVI 孩子听觉往往比视觉好，
  声音奖励会让孩子学会"靠听得分"，视觉通路就被绕过去了。
- `ALERT` 的 `0x02` 常亮是呈现训练目标的默认模式，`0x03` 呼吸用于吸引注意。

要开始时的第一步：把 `apps/parent/src/transport/` 那一套挪成共享包，
然后儿童端只写 UI 与判分接入。
