# 家长端 App（iPad）

这个目录是**家长端**的设计与 P0 代码，和仓库根目录 `dist/` 里的儿童游戏是**两套独立的东西**。

| | 儿童游戏（根目录 `dist/`） | 家长端（本目录） |
| --- | --- | --- |
| 谁用 | 孩子（第 1–3 阶） | 家长 |
| 跑在哪 | 浏览器，可直接打开 `dist/index.html` | iPad App，Vite + Capacitor |
| 现在用什么技术 | 纯静态 HTML/CSS/JS | TypeScript + 单元测试 |
| 怎么启动 | `npm run dev`（根目录） | `./dev.cmd`（本目录） |

两套代码不共用构建、不共用依赖，互不覆盖。根目录的 `npm run dev` 仍然只启动儿童游戏。

---

## 现在做到什么程度

**已完成（P0）**

- BLE 协议层：`ALERT` / `LIGHT` / `MOTION` 的编解码、安全档位、字节表
- 回合门控状态机：`idle / presenting / gating`，解决"MOTION 只在状态变化时推送"这个坑
- 指标：命中率、P50/P90 反应潜伏期、疲劳斜率（不用均值，长尾会把均值毁掉）
- 用量积分：读不到电量，用"亮灯分钟 × 亮度"折算
- 灯光安全策略：光敏癫痫史自动禁用闪烁并压低亮度；触觉敏感自动关马达
- 家长端界面：训练 / 数据 / 设备 / 我的 四个 Tab
- 孩子模式：全屏、纯黑底、单目标、右上角长按退出
- 实物训练台：第 4 阶自动回路（亮 30 秒 / 间隔 8 秒 / 10 轮）
- 82 个单元测试 + 页面冒烟测试

**还没做**

- iOS 原生蓝牙桥接（CapacitorTransport）——需要在 macOS 上生成 iOS 工程
- 素材拍摄提纯、PDF 周报、云端同步

**这一版不接真实硬件也能看界面**：没有蓝牙时自动切模拟设备。

## 运行

和根目录的儿童游戏一样，只需要 **Node.js 20 或更新版本**，不需要另外装 pnpm 或其它工具。

**最简单的方式**：双击本目录下的 `dev.cmd`。
它会在第一次运行时自动装依赖，然后起开发服务器，浏览器打开 `http://localhost:5180`。

**或者用命令行**：

```sh
cd parent-app
npm install      # 第一次需要，之后不用
npm run dev      # 浏览器打开 http://localhost:5180
```

跑测试：

```sh
./test.cmd       # 82 个测试 + 类型检查
# 或
npm test
npm run typecheck
```

> 第一次 `npm install` 大约十几秒，会装 180 个左右的包。它们都装在 `parent-app/node_modules` 里，不会影响根目录的游戏。

## 和儿童游戏的关系

目前**没有代码级衔接**，两者的联系只在这几条约定上：

1. **CVI 三阶段与交互方式独立配置**，不把游戏成绩换算成临床阶段或康复分数——这条和根目录 `AGENTS.md` 一致。
2. **"悬停"是接触目标并停留 1.2 秒**，不是隔空识别。家长端的交互方式选项用的是同一口径。
3. 家长端演示数据为构造的示例，**不代表任何真实儿童的表现**。

将来如果要把两边连起来，边界应该是：儿童游戏负责"呈现与判分"，家长端负责"计划、数据、建议"。
判分口径必须只有一处定义，不能两边各算一遍。
