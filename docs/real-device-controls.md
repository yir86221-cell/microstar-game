# 0.1.5 真实设备功能

依据为用户提供的 micro_star_client.js 与 micro_star_parent.html。未读取设备固件源码，不能推断额外指令。

| 功能 | 处理与依据 |
| --- | --- |
| 连接、停止并断开 | 接入 Android 原生 BLE；浏览器使用 Web Bluetooth。失败显示真实错误，不回退模拟灯。 |
| 闪烁启停 | 原始 ALERT 01 / 00。写入成功只说明指令已发送，是否实际亮灯需要观察。 |
| 红/黄/暖白/蓝、亮度 | LIGHT 原始五字节；亮度最多 128，沿用档案的较低限制。颜色写入不会自动发启动指令。 |
| 试灯、找灯 | 分别发送 2 秒、3 秒的闪烁再停止，沿用档案禁闪及关闭震动限制；没有擅自定义固定闪烁次数。 |
| 读取状态 | 主动读取 STATUS 0005，显示设备返回的闪烁、运动标记、IMU 状态及读取时间。读失败或数据无效不编造状态。 |
| 常亮、呼吸 | 删除。提供的固件示例只定义 ALERT 00/01，没有对应模式指令。 |
| 电量、剩余次数 | 删除原设备页的续航估算；协议无电池电量字段，不能当作设备实测。 |
| 自检通过/灯已亮 | 删除自动判定。蓝牙写入成功不能证明光输出已正常。 |
| 模拟拿起/放下、调试台、模拟连接 | 删除入口及对应实现，设备页不会假装连接。 |
| 实物自动训练/自动命中计分 | 删除训练启动按钮、页面和实物回路设置。示例中的运动标记不能等同于抓握成功，不以此生成训练成绩。 |

实物训练页保留真正的手动控灯按钮及设备页入口。前三阶段真实启动游戏的按钮保留；删除不生效的实物时长、悬停参数展示。已有用户数据不清空；数据页明确标记的演示数据功能不在本次按钮修改范围。

设备页离开、关闭家长端或切到后台时尝试停止并断开；选择过程中离开会取消选择，延迟返回的连接不会启动灯。设备页自行更新状态，调整颜色不会因页面重绘断开。

测试：npm run check、npm test、124 项家长端测试、类型检查和 APK 构建通过；签名与旧版相同，12 个 Web 文件一致。浏览器检查手机 412×915、平板 1024×768；预览截图位于本地 releases/v015-*.jpg。无真实手机/灯具连接，不能声称硬件已实测成功。

仅提交独立安卓分支，不合并 main，不发布 Sites。共享网页源码也使用真实 Web Bluetooth；电脑端 main 尚未同步此次改动。
