# 第三阶段：实物照片

安卓 0.1.7 与该分支的电脑网页共用同一套照片关卡。分支 `codex/android-v0.1.7-photo-levels` 基于安卓 0.1.6，不合并 main，也未更新 Sites。

## 使用

1. 长按右下角家长入口，进入「训练 → 实物照片」（第三阶段）。
2. 点「拍照制作关卡」，选择「拍照」或「从相册选择」。电脑可选图片文件。
3. 查看照片预览，填写关卡名称，点「保存并返回训练」。新关卡会自动选中。
4. 点「开始训练」，儿童端使用同一张照片；也可从儿童端 Phase III 进入。

保留照片真实颜色、纹理和背景；建议家长在简单背景下拍摄单件物品。图片等比例压缩，最长边不超过 768 像素，训练时等比例显示。没有自动单色化或云端抠图。

第三阶段只列出本机保存的照片关卡，不再默认进入立体黄杯或旧卡通关卡。尚未制作照片时显示制作提示。每关使用单张图片作为目标，仍支持拍击、精准点击和接触停留 1.2 秒；回应三次后进入下一张，最后一张结束后打开关卡菜单。

## 管理与存储

- 「拍照制作关卡」下方可改名、更换照片或删除。删除不清除已有训练记录；删除最后一张后回到待制作状态。
- 照片在当前设备、当前浏览器或 App 本地保存，不上传到仓库或服务端；不同设备和浏览器之间不自动同步。
- 旧版已保存的自制关卡保留。旧版单色轮廓无法恢复原始照片，可用「更换照片」重新拍摄。
- 存储不足会显示失败提示并保留当前预览，不会显示为保存成功。卸载 App 或清除其数据会丢失本机照片。
- 拍照或选择图片后离开制作页，未保存的草稿会丢弃。

## 验证

根目录检查与回归测试、家长端原有 124 项测试及新增 4 项照片测试、类型检查通过。覆盖保存与重载、存储失败、空关卡、离开制作页、三种输入、暂停、记录、关卡编号对应，以及删除当前照片后返回。

浏览器使用本地测试图片实际验证：选图、预览、命名保存、刷新保留、儿童端 Phase III 显示、嵌入家长页启动同一照片。检查 412×915 手机与 1024×768 平板布局。测试图片不随 APK 发布。

尚未连接真实安卓手机；系统相机调用、相册授权及真机覆盖安装需要实测。前两个阶段与第四阶段灯控保持原有功能。
