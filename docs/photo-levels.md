# 第三阶段：实物照片与主体抠图

安卓 0.1.9 与该分支的电脑网页共用同一套制作功能。分支 `codex/android-v0.1.9-cutout-worker` 基于安卓 0.1.8，不合并 main，也未更新 Sites。

## 制作与修整

1. 长按右下角家长入口，进入「训练 → 实物照片」（第三阶段）。
2. 点「拍照制作关卡」，选择「拍照」或「从相册选择」。电脑可选图片文件。尽量单件居中、拍完整、使用简单背景。
3. 选图后在本机识别中央主体。若选错物品，选「点选主体」后点击编辑区内希望保留的物品。
4. 用「擦除」去掉多余背景，「补回」找回被误删的边缘，画笔大小可调。「撤销」保留最近 10 步；「原图对照」查看未处理照片。「重新抠图」再次选择中心；「恢复完整原图」恢复全部照片。
5. 检查「黑底训练效果」，填写关卡名，点「保存并返回训练」。透明主体会等比例居中，原始颜色和纹理保留。
6. 点「开始训练」，儿童端使用同一张抠图；也可从儿童端 Phase III 进入。

编辑区保留暗淡背景以方便定位，黑底训练预览只显示保留区域。自动识别不是每次都准确，复杂背景、透明物体或细小边缘可能需要修整。没有识别成功时明确显示提示，仍可手动擦除、补回；空白结果不能保存。

第三阶段只列出本机保存的照片关卡；尚未制作时显示提示。每关使用单张图片作为目标，仍支持拍击、精准点击和接触停留 1.2 秒；回应三次后进入下一张，最后一张结束后打开关卡菜单。前两个阶段与第四阶段灯控保持原有功能。

## 管理与存储

- 「已拍的实物」可改名、编辑 / 更换照片或删除。删除不清除已有训练记录；删除最后一张后回到待制作状态。
- 每关保存最长边 768 像素的压缩原图、编辑范围与透明 PNG 结果；保留的是压缩副本，不是相机原文件。可重新打开编辑，再次保存会替换同一关卡，不另造重复关卡。
- 0.1.7 的完整照片可继续抠图；更旧版本只有轮廓图时无法还原丢失的原照片，需重新拍摄。
- 照片仅在当前设备、当前浏览器或 App 本地保存，不上传，不自动跨设备同步。
- 存储不足显示失败并保留当前预览，不会显示为保存成功。卸载 App 或清除数据会丢失本机照片，更新请覆盖安装。
- 离开制作页或取消照片，会丢弃未保存的草稿。

## 本机模型与构建

使用 MediaPipe Interactive Segmenter（MagicTouch）点选分割。模型、WASM 运行文件和许可随 APK 打包；App 抠图无需联网。电脑网页加载同站点的资源，首次需要能访问该网站；未实现完整模型的网页离线缓存。

`npm --prefix parent-app run dev` 和根目录 `npm run build:parent` 会执行 `scripts/prepare-cutout.cjs`。首次构建从 Google 官方存储下载约 30.5 MB 模型并验证固定 SHA-256；之后校验和复用本机缓存。模型或地址变更不能跳过校验，需要明确审核更新。生成的资源目录不提交 Git。发布网页时须完整包含 `dist/parent/cutout/`。

模型加载、图片解码、CPU 推理与蒙版转换均在专用后台线程中进行，页面保留原图预览，可滚动、填写名称或取消。识别超过 45 秒会终止后台线程；取消/超时不覆盖已有编辑结果，可重新尝试。离开制作页也终止计算。不支持后台运行时明确提示并保留手动编辑，不回退到页面线程执行模型。计算总时长仍取决于设备，不承诺立即完成。来源、模型校验值和 Apache 2.0 许可见 `third-party-cutout.txt`、`Apache-2.0-cutout.txt`。

## 验证范围

根目录 `npm run check`、`npm test`、家长端 144 项测试与类型检查通过。新增覆盖后台任务取消、超时、重试、关闭、迟到结果、模块运行文件加载及资源释放；保留坐标与留白映射、擦除/补回、颜色与透明区域、模型资源及释放、保存原图/编辑范围、存储失败、取消异步选图，保留原有三阶段训练和设备控制回归。

0.1.9 浏览器验证真实后台模型、识别期间填写名称、取消后保留结果及重试成功。使用合成红杯测试图实际运行本机模型，检查点选识别、擦除、补回、撤销、保存、刷新后重新编辑，以及 412×915 手机与 1024×768 平板布局。测试图片不随 APK 发布；这不代表复杂真实照片的识别质量已经全面验证。

未连接真实安卓手机；系统相机、真机触控、WebView 推理性能与覆盖安装仍需实测。
