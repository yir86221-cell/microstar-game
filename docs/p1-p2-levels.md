# 当前版本：P1 改进，恢复原 P2 / P3

本次按用户纠正执行。先前 P2 十关重做已撤回，软件仍保留 P1、P2、P3 三个入口。

## P1（10 关）

1. 星球点亮：黄色圆球点击一次，反馈结束后自动进入下一关。
2. 点亮小星星：黄色星星点击一次，反馈结束后自动进入下一关。
3. 色彩探索：红黄蓝三球横排，依次引导点击。亮起与反馈保留鲜艳原色，通过同色光晕增强提示，不变成浅白色。
4. 形状朋友：绿色圆形、正方形、三角形依次出现。
5. 大小星球：橙球从左侧小球开始，三次点击逐段加速并长大，抵达右侧终点。
6. 躲猫猫：粉球隐藏后依次在左侧、右下角、左上角再出现；每轮只显示一个球。首次可手动启动，后续点击反馈结束后自动短暂藏起，再在新位置出现。
7. 星球换位置：鲜亮紫色（#b128ff）圆球左、中、右依次定位。
8. 上下找星星：粉色星星沿上 → 下 → 上 → 下移动，三次点击分别加速一段。
9. 漂流星球：绿色圆球从左向右前进，三次点击加速三段，到达右侧终点。
10. 星光旅行：鲜亮紫色（#b128ff）圆球沿左上→中上→右上→右下的路径分三段前进。每次点击推动一段加速，第三次实际到达右下终点后成功。

### 三次推动的交互

第 5、8、9、10 关初始静止，可先观察，点击“开始运动”后慢速移动；也可以直接触碰发起第一段加速。
每次有效点击播放轻柔音效与发光轻晃，并推动下一段移动，运动不会在点击瞬间停止。
每段加速约 0.9 秒（降低难度时约 1.2 秒），该段加速中重复点击不重复计数；到达中间点后继续慢速前进，等待下一次推动。
没有第三次输入不会自动到达终点；第三次输入后仍需完成末段实际运动，随后反馈并成功。
暂停、菜单、切到后台会冻结移动和计时；重玩清除进度。

## 新增 P2 第五关与阶段衔接

P1 第十关最后一段移动完成，播放终点反馈后，直接显示 P2 第一关；不显示中间菜单或阶段选择。保留当前交互模式与声音设置，先保存 P1 完成记录再切阶段。

P2 第五关“小猪快跑”：黑背景，粉色侧面小猪朝右，左侧一丛绿色草。两种主体都为大块纯色 SVG，不加入场景纹理或背景装饰。
初始静止等待；点击后尾巴轻摆约 0.9 秒，随后小猪约 2.2 秒加速跑到屏幕右侧之外，完全离开后反馈成功。
一次有效回应即可完成；动画中重复点击不重启、不重复计数；支持精准点击、全屏拍击、接触停留 1.2 秒。
