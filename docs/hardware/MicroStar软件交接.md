# 微动星瞳软件交接

给软件交互设计。可运行的测试页是同目录下的 `micro_star_train.html`。页面里的连接、写颜色、写指令、解析通知都是实际代码，产品界面按这些调用封装。不要发送串口文字。

设备蓝牙名称是 `MicroStar`。没有配对码。同一时间连接一部手机，断开后会重新广播。

## 1. 设备在交互里做什么

模块放在物品外面，灯和超声波朝向要找的那件物品。奖励卡在物品底下，上面没有电路。

交互分两段：

1. 调试。手机确认红、绿、蓝、暖白和亮度峰值，并可以试灯。试闪是亮 200 毫秒、灭 200 毫秒。试恒亮用来看峰值。
2. 训练。家长把模块对准物品，等距离稳定后点“开始找”。灯按刚确认的颜色和亮度恒亮，颜色被锁定，直到这次训练结束。距离比开始时的初始值大 3 厘米以上，设备判定拿起：灯改为约 2 秒一周期的正弦呼吸，马达自己短震 3 下，并把用时发给手机。

手机不发送震动指令，也不控制呼吸的快慢。手机负责确认颜色、试灯、开始找、结束训练，并记录找到所用的时间。

亮度峰值大于 128 时，设备会收成 128。暖白是单独一路，不能只用红绿蓝配出来。

## 2. 怎么打开测试页

在 `software` 目录执行：

```text
python -m http.server 8080
```

用电脑上的 Chrome 打开 `http://localhost:8080/micro_star_train.html`。不要双击 html。设备先上电，页面上点“连接设备”，选择 `MicroStar`。

## 3. 服务和特征

服务 UUID：

```text
8a1f0001-3c4d-4e5f-9a6b-7c8d9e0f1a2b
```

四个特征只有第二段不同，不要改这些值。

| 特征 | UUID | 权限 | 用途 |
|---|---|---|---|
| 指令 | `8a1f0002-3c4d-4e5f-9a6b-7c8d9e0f1a2b` | 读、写、通知 | 试灯、开始找、结束训练 |
| 颜色 | `8a1f0003-3c4d-4e5f-9a6b-7c8d9e0f1a2b` | 读、写 | 调试时写入 5 字节颜色 |
| 测距 | `8a1f0004-3c4d-4e5f-9a6b-7c8d9e0f1a2b` | 读、通知 | 设备每约 400 毫秒推送 10 字节 |
| 总状态 | `8a1f0005-3c4d-4e5f-9a6b-7c8d9e0f1a2b` | 读 | 需要时再读。界面以测距通知为准 |

连接后要打开测距特征的通知。通知描述符 UUID 是 `00002902-0000-1000-8000-00805f9b34fb`，写入 `01 00`。测试页里的 `startNotifications()` 会做这件事。

## 4. 手机写给设备的字节

颜色特征正好 5 个字节：红、绿、蓝、暖白、亮度。调试阶段写入后会被记住。训练开始后再次写入会被丢掉，灯保持原来的颜色。只写颜色不会开灯。

指令特征写 1 个字节：

| 字节 | 作用 |
|---|---|
| `00` | 关灯，并结束训练，颜色重新可以改 |
| `01` | 调试：按已确认的颜色闪烁 |
| `02` | 调试：按已确认的亮度恒亮 |
| `10` | 开始找。记下当前距离作为初始值，灯恒亮，开始计时 |
| `11` | 结束训练，关灯，解锁颜色 |

训练进行中，`01` 和 `02` 不会改变灯。已经开始后再写一次 `10`，会用眼前的新距离重新作为初始值，并重新计时，颜色仍然不变。没有有效距离时，`10` 不会开始。

测试页对应关系：

| 页面按钮 | 写入 |
|---|---|
| 确认颜色、暖白、红色 | 颜色特征，5 字节 |
| 试灯闪烁 | 指令 `01` |
| 试灯恒亮 | 指令 `02` |
| 关灯 | 指令 `00` |
| 开始找 | 指令 `10` |
| 结束训练 | 指令 `11` |

## 5. 设备推给手机的 10 字节

测距通知是小端字节序。测试页用 `getUint16(2, true)` 和 `getUint32(6, true)` 读取。

| 字节 | 含义 |
|---|---|
| 0 | 阶段。`0` 调试，`1` 寻找中，`2` 已找到 |
| 1 | 标志。bit0 为 1 表示这次距离有效；bit1 为 1 表示最近几次读数变化不超过 1 厘米 |
| 2–3 | 当前距离，单位毫米 |
| 4–5 | 开始找时记下的初始距离，单位毫米。调试阶段为 0 |
| 6–9 | 从开始找到判定拿起的用时，单位毫秒。寻找过程中会持续增加，阶段变成 `2` 后停住 |

界面显示厘米时，把毫米除以 10。阶段变成 `2` 时，第 6 到第 9 字节就是这一次找到所用的时间，可以直接记录。

总状态是 3 个字节，不主动推送：灯的模式、是否已找到、距离是否有效。灯的模式为 `0` 关、`1` 闪、`2` 恒亮、`3` 呼吸。

## 6. 交互约束

- 开始找之前，页面应让家长看到当前距离，以及读数是否稳定。稳定只是提示，真正开始仍由家长按下“开始找”。
- 判定拿起的阈值在设备里，是比初始距离大 3 厘米，并连续两次读到。手机不要自己再用另一套阈值改结果。
- 一次训练的颜色和亮度以按下“开始找”之前最后一次成功写入的 5 字节为准。
- 马达只在判定拿起时短震 3 下。界面不要做震动按钮。
