## 如何安装与更新

从 [GitHub 安卓发布列表](https://github.com/yir86221-cell/microstar-game/releases) 下载 `microstar-android-v0.1.10.apk`，打开并确认覆盖安装。不要先卸载，以免清除本机记录。

0.1.2 及之前版本不含更新功能，必须先手动安装一次 0.1.3 或更高版本。之后：

- 启动 App 时后台检查 GitHub 的安卓发布列表；返回前台、进入家长端时也检查，同一进程最多每小时自动请求一次。
- 家长空间右上方显示“检查更新”；发现新版时变为“有新版本”。点击后显示版本与 APK 下载按钮，不打断儿童游戏。
- 手动检查不受一小时限制；检查失败会区分接口限流、HTTP 错误、超时、返回数据异常与连接失败，并提供浏览器下载页入口，不影响本地游戏。
- 下载使用手机浏览器，完成后需要用户打开 APK 并确认安装。没有后台静默安装，也没有远程替换游戏代码。
- 只有发布了 `android-vX.Y.Z` 标签及同版本 APK 的 GitHub Release 才会被识别；包含测试版 prerelease，忽略草稿和没有 APK 的版本。仅推送代码或合并 main 不会更新手机。
- 不向更新接口发送儿童档案、训练记录或照片；请求仅用于读取公开版本列表。接口限流时按提示等待，或切换代理节点、使用浏览器下载页；整个 GitHub 都不可访问时仍需恢复网络访问。

### 0.1.10 新硬件测距训练

电脑 Web Bluetooth 与安卓原生 BLE 均支持测距通知；准备颜色/亮度、试闪/恒亮、开始找、结束训练。按设备确认推进状态；无有效距离不开始，重复开始不重发，重复完成只记录一次，断线/数据超时按中断处理。需新版 10 字节测距固件，不兼容旧 IMU 数据。不会发送 0x03 呼吸或 0x80 震动屏蔽指令。详见 [测距训练说明](range-training.md)。

### 0.1.9 后台抠图修复

0.1.8 在页面线程使用 CPU 执行模型，手机选图后可能整页无响应。本版将模型初始化、图片解码、编码推理及蒙版转换放入模块 Worker，复用同一照片的模型状态。识别过程显示阶段与秒数，可取消；45 秒超时、取消及离开页面均实际终止线程，保留原图和上次编辑结果。不支持后台模型时提供手动修整，不再回退到会阻塞页面的模型路径。

根目录检查、144 项家长端测试、类型检查通过。浏览器实际验证后台识别成功、识别期间输入、取消/重试及手机和平板布局；尚无真机性能或触控验证。离线使用，不接入云端或使用 API 密钥。

### 0.1.6 代理出口限流提示

用户在同一手机开启代理后访问更新接口，看到 `rate limit / 请求过多`，确认不是手机未联网。旧版把所有错误统一显示为“请联网后重试”；本版识别 HTTP 429，以及带额度耗尽或限流信息的 HTTP 403。普通 403 不直接判断为限流。接口提供有效恢复时间时显示本机时间。

GitHub 的[官方限流说明](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)规定：未认证请求按来源 IP 计算，每小时通常 60 次，共享代理出口可能被其他用户消耗额度。本次没有提高或绕过 GitHub 额度；新增的普通版本下载页入口可在 API 被限流时手动查看和下载，仍取决于该网络能否访问 GitHub 网页与下载服务。

## 本地重新构建

工具：Node.js 22+、JDK 21、Android SDK Platform 36 / Build Tools 36.0.0。
项目锁定 Capacitor 8.6.0；Gradle Wrapper 随工程保存，首次构建需要联网下载构建依赖。

```sh
npm ci
npm --prefix parent-app ci
npm run check
npm test
npm --prefix parent-app test
npm --prefix parent-app run typecheck
npm run android:apk
```

构建命令依次重建家长端、同步 Web 资源到 Android、编译调试 APK、复制到 `releases/` 并计算 SHA-256。
脚本优先读取 `ANDROID_HOME` / `ANDROID_SDK_ROOT`，也会查找系统常见 SDK 目录；SDK 路径仅写入此目录下被 Git 忽略的 `android/local.properties`。
JDK 使用 `JAVA_HOME`，未设置时使用 PATH 上的 Java。中文路径下直接调用 Java 启动 Gradle Wrapper，避开 cmd.exe 对中文路径的编码问题。

后续只同步资源可运行 `npm run android:sync`；已安装 Android Studio 时可运行 `npm run android:open`。
代码、SDK 路径、构建缓存、APK 和签名的边界在 `.gitignore` 中定义；不要提交签名文件或本机配置。
