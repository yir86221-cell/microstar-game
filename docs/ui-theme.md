# 界面统一（2026-11-23）

以当前家长端为基准：深灰背景、薄荷绿操作色、圆润卡片、胶囊按钮。儿童游戏区域继续使用纯黑底与原有高饱和目标，不改变物体颜色、大小配置、轨迹、奖励或输入规则。

- 儿童界面主题集中在 `dist/ui-theme.css`，由 `dist/index.html` 在原样式之后加载；主要覆盖导航、阶段选择、菜单、暂停、家长弹窗、设备选择与更新提示。
- 家长界面的统一样式位于 `parent-app/apps/parent/src/style.css` 末尾，沿用现有变量。包含训练、数据、设备、个人设置、照片关卡与编辑工具。
- 关卡菜单保持大预览和任务名称，删除数字前缀；短横屏将选关和操作设置分列，各自可滚动。保留右下角家长长按入口，并为它预留按钮空间。
- 选中态同时使用底色、文字或勾选标记；键盘焦点清晰可见。所有新增动画响应系统的减少动态效果设置。

验证：儿童端检查与回归、家长端 167 项测试和类型检查、生产构建通过。浏览器检查 1024×768 平板、844×390 手机横屏与 390×844 手机竖屏；家长训练、数据、设备、我的页面无横向溢出。真实设备触控及蓝牙联调不属于本次视觉验证。

共享站点存在 25 MiB 单文件限制，照片抠图模型沿用已有分片加载适配；该托管适配不写入团队主分支。
