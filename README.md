# 微动星瞳游戏 Demo

## 安卓独立分支

安卓基础分支为 `feature/android-v0.1.0-app`；本次 0.1.8 主体抠图独立保存在 `codex/android-v0.1.8-photo-cutout`，包含此前家长入口及真实设备控灯。
电脑控灯此前已合并 main；本次安卓开发在独立 worktree 中完成，不合并 main，也不更新 Sites 网站。

测试安装包：`releases/microstar-android-debug.apk`（本地构建产物，不进 Git）。
安卓 0.1.8 测试包通过 [GitHub Releases](https://github.com/yir86221-cell/microstar-game/releases) 提供；可覆盖安装旧版，尚未上架应用商店。首次需手动安装 0.1.3 或更高版本，以后联网打开 App 或返回前台时会检查新版，家长空间提供“检查更新 / 有新版本”入口。下载后仍需确认安装。0.1.6 区分更新接口限流与连接错误，检查失败时提供浏览器下载页入口。
0.1.8 在拍照制作关卡中加入本机主体抠图、擦除/补回、撤销和黑底预览，保留原色及压缩原图。模型随 App 打包，抠图不需要联网；首次源码构建需下载约 30.5 MB 模型。
安装、构建、已验证内容和限制见 [安卓测试版说明](docs/android-app.md)。

在安装 Node.js 22+、JDK 21、Android SDK 36 后首次执行：

```sh
npm ci
npm --prefix parent-app ci
npm run android:apk
```

儿童端和构建后的家长端均打包在 APK 内，启动不依赖电脑或试玩网站。

这是儿童游戏端的可交互原型，供小组讨论界面、玩法与操作方式。右下角家长入口可以打开家长端（架构、界面与 P0 代码都在 `parent-app/`）。本分支新增第四阶段手动蓝牙控灯按钮，说明见 [控灯使用说明](docs/phase4-manual-lamp.md)；0.1.5 已移除实物阶段的演示启动与模拟设备，设备页改用真实蓝牙控制；支持范围见 [真实设备功能说明](docs/real-device-controls.md)。

## 运行

安装 Node.js 20 或更新版本后，在项目文件夹运行：

```sh
npm run dev
```

浏览器打开终端显示的 `http://127.0.0.1:4173`。不需要安装第三方依赖。也可直接用浏览器打开 `dist/index.html`。

## 当前内容

完整软件保留 P1「发现目标」、P2「认识物品」、P3「实物照片」三个阶段入口。
P1 共 10 关，前两关黄球、黄星各一次回应后自动进入下一关；第三关红黄蓝小球依次点击，发光保持鲜艳原色。
P1 第 5、8、9、10 关使用三次点击逐段加速，到终点后成功；第 6 关在左侧、右下、左上不同位置再出现。后续关卡分别使用绿色、橙色、粉色与紫色。
P2 保留小鸡、小车、苹果、小星星四个示例任务，新增第 5 关“小猪快跑”：点击侧面小猪，先摇尾巴再跑出屏幕。P2 第 6–10 关新增苹果落地堆叠、熊猫吃竹子、眨眼蛋飞走、苹果长叶子和影子匹配。P3 使用家长拍摄或选择的实物照片；没有照片时提示到家长端制作，操作见 [照片关卡说明](docs/photo-levels.md)。P2 最后一关完成后直接进入 P3。P1 最后一关完成反馈后直接进入 P2 第一关。

菜单支持选关、拍击/精准点击/接触停留；P1 新增关卡支持声音与降低难度设置。说明见 [当前关卡说明](docs/p1-p2-levels.md)。
所有内容均为软件原型，表现仅供观察，不换算为临床分级或疗效。

## 修改哪个文件

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 页面入口与基础说明 |
| `dist/style.css` | 黑底配色、大小、布局、横竖屏适配和动画 |
| `dist/game.js` | 物体图形、关卡名称、任务逻辑、输入方式和菜单 |
| `preview.mjs` | 本机预览服务 |
| `TASKS.md` | 团队进度与待办 |
| `CONTRIBUTING.md` | 小组共同修改流程 |

`game.js` 中的 `arts` 是物体素材，`levels` 是关卡文案，`modes` 是交互方式；`S` 保存当前会话状态。前两阶段使用代码绘制素材；第三阶段使用本机保存的实物照片。

## 协作与发布

当前按小组决定使用公开 GitHub 仓库作为代码的统一来源。公开可读，编辑权限仍需邀请或通过合并请求协作。一个修改建一个分支，经另一位组员检查后合并。具体步骤见 `CONTRIBUTING.md`。

## 家长入口整合

右下角家长入口打开的是完整的家长端（四个 Tab + 孩子模式 + 实物训练台），打开期间儿童游戏暂停，返回保留关卡和进度。

家长端读的是儿童端写在本机同一份存储里的成绩：孩子在游戏里打完一关，家长端点开就能看到这条记录（列表里标「儿童端」）。第四阶段（实物训练）只在家长端，它产生的是「实物」记录。

### 第一次必须先构建

`dist/parent/` 是构建产物，**不进仓库**。所以刚克隆下来直接打开 `dist/index.html`，点右下角家长入口会是一个空白页。

先做一次：

```sh
cd parent-app
npm install          # 只需一次
cd ..
npm run build:parent # 把家长端打包进 dist/parent
```

之后 `npm run dev` 就能同时预览两端。发布前也要重跑一次 `npm run build:parent`，把 `dist/parent` 和儿童端一起部署。生成文件不手工修改。

### 在平板上演示蓝牙

只有**安卓平板**能连灯。iPad 上的 Safari 和 Chrome 都不支持网页蓝牙（iOS 强制所有浏览器用 WebKit），Firefox 任何平台都不支持。

还有一条更隐蔽的限制：**网页蓝牙只在 HTTPS 或 localhost 下可用**。用 `http://192.168.x.x:5180` 从平板访问，蓝牙会直接不可用，而且没有明显报错。

所以演示要走 HTTPS，两条路：

- 把 `dist/` 整个部署到任意 HTTPS 静态托管（GitHub Pages、Netlify Drop 等都行）
- 或者用 `chrome://inspect` 的端口转发，让平板把 `localhost:5180` 映射到电脑上

家长端已带 PWA 清单，安卓上用 Chrome「添加到主屏幕」后可以全屏打开，没有地址栏；孩子模式也会在开始训练时申请全屏。
